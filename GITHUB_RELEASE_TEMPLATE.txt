🎉 GarosNotes v1.4.0 - Notas de Lanzamiento
==========================================

Título: GarosNotes v1.4.0 - Sistema Vite & Stack Frontend Moderno

Descripción:
-----------

Actualización importante con integración del sistema de construcción Vite, dependencias frontend modernas y mejoras de rendimiento.

✨ Novedades:
- 🛠️ Integración de Vite para bundling optimizado y construcciones más rápidas
- 📝 Actualizado a Quill 2.0.3 para mejor edición de texto
- 🎨 Resaltado de sintaxis mejorado con soporte para 13+ lenguajes de programación
- ⚡ Rendimiento mejorado con renderer optimizado (45 líneas de código redundante eliminadas)
- 🏗️ Mejor arquitectura con configuración de workspace en pnpm

🔧 Cambios Técnicos:
- Sistema de construcción actualizado: src/ → dist/
- Nuevos scripts: dev, build (ahora incluye Vite)
- Soporte para pnpm workspace
- Manejo de eventos refactorizado en renderer

📊 Estadísticas:
- 9 archivos modificados
- 704 inserciones, 159 eliminaciones
- 0 cambios críticos
- 100% compatible con versiones anteriores

🚀 Instalación:
pnpm install
pnpm run dev      # Desarrollo
pnpm run build    # Crear instalador

📦 Descargas:
Usa los instaladores en los activos de la versión para instalar en Windows.

💡 Notas:
- Sin cambios críticos respecto a v1.3.0
- Seguro para actualizar
- Vite proporciona mejor experiencia de desarrollo y construcciones más rápidas

🙏 Agradecimientos Especiales:
¡A los contribuidores y miembros de la comunidad por sus comentarios y apoyo!

Major update with Vite build system integration and modern frontend stack!

🌟 **Key Improvements:**
- Integrated Vite for ultra-fast bundling and development
- Upgraded to Quill 2.0.3 editor and highlight.js for better code highlighting
- Optimized renderer with 45 lines of redundant code removed
- Improved pnpm configuration with workspace support

📝 **What Changed:**
- Build process now uses Vite (src/ → dist/)
- New `dev` script: `vite build && electron .`
- Updated `build` script with Vite compilation
- Better dependency management

✅ **Compatibility:**
- No breaking changes
- Fully backward compatible
- Safe to upgrade from v1.3.0

🚀 **Getting Started:**
```bash
pnpm install
pnpm run dev      # Development
pnpm run build    # Production installer
```
